# Enterprise SOC Lab: Detection Engineering & Incident Response Platform

## 📌 Overview
This project simulates a real-world enterprise Security Operations Center (SOC) environment using Splunk SIEM.

The lab includes:
- Active Directory environment
- Centralized logging with Splunk
- Attack simulation (brute force, credential dumping, lateral movement)
- Detection engineering using custom rules
- Incident response workflows aligned with MITRE ATT&CK

---

## 🏗️ Architecture

| System | Role |
|--------|------|
| DC01 | Domain Controller |
| WIN10 | Employee Workstation |
| SPLUNK | SIEM Server |
| KALI | Attacker Machine |

---

## 🎯 Objectives
- Simulate real-world cyber attacks
- Detect threats using SIEM
- Build incident response workflows
- Improve detection through analysis
